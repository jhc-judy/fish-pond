# fish-pond
Interactive animation system for Memory of the Fish Jar, an in-progress sculpture combining hand-carved wood, stone, sound sensing, and real-time digital animation.

The present prototype includes:
- Three independently moving red fish
- Ripple generation and propagation
- Fish reactions when a ripple reaches them
- Accumulating disturbance behavior from repeated interactions
- Gradual return to calmer movement

Mouse input is currently used to simulate disturbances during development.

# Software
Python
Pygame

# Project Structure
main.py — application entry point
pond.py — pond environment and interaction logic
fish.py — fish movement and behavior
ripple.py — ripple generation and propagation
